## What Was Researched This Session

### ProjectX Gateway API — Full Analysis

**Base URL:** `https://api.topstepx.com`
**Real-time hubs:** `https://rtc.topstepx.com/hubs/market` and `/hubs/user` (Microsoft SignalR / WebSocket)

**Complete API surface:**
- `POST /api/Auth/loginKey` — API key auth → JWT token (24hr)
- `POST /api/Auth/validate` — refresh token
- `POST /api/Account/search` — get account ID, balance, canTrade
- `POST /api/Contract/available` — list all active contracts
- `POST /api/Contract/search` — search by name (e.g. "MNQ")
- `POST /api/History/retrieveBars` — OHLCV bars (unit: Second/Minute/Hour/Day; max 20k bars; rate limit 50/30s)
- `POST /api/Order/place` — place orders (Market, Limit, Stop, StopLimit, TrailingStop; includes bracket orders)
- `POST /api/Order/cancel` — cancel order
- `POST /api/Order/modify` — modify size/price
- `POST /api/Order/searchOpen` — open orders
- `POST /api/Position/searchOpen` — open positions
- `POST /api/Position/closeContract` — close full position
- `POST /api/Position/partialCloseContract` — partial close
- `POST /api/Trade/search` — trade history with P&L per trade

**Real-time WebSocket (SignalR):**
- Market Hub: `SubscribeContractQuotes` → live bid/ask/last/volume
- Market Hub: `SubscribeContractMarketDepth` → full DOM
- Market Hub: `SubscribeContractTrades` → tick-by-tick
- User Hub: `SubscribeAccounts/Orders/Positions/Trades` → live account state

**Rate limits:**
- `/api/History/retrieveBars`: 50 req / 30 sec
- All other endpoints: 200 req / 60 sec

**Bracket order example (place entry + SL + TP in one call):**
```json
{
  "accountId": 1,
  "contractId": "CON.F.US.MENQ.H25",
  "type": 2,
  "side": 0,
  "size": 1,
  "stopLossBracket": {"tickDistance": 40, "type": 4},
  "takeProfitBracket": {"tickDistance": 80, "type": 1}
}
```
